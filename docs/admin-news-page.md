# 관리자 뉴스 승인 페이지 (프론트 작업 요청)

작성일: 2026-10-22

백엔드에서 네이버 뉴스 검색과 승인 API를 제공합니다. 이 문서는 프론트에서 만들어야 할 **관리자 화면**을 정리합니다.
백엔드 API는 구현되어 있습니다(`news` 패키지). API가 바뀌면 이 문서도 함께 고칩니다.

## 목적

관리자가 네이버 뉴스 검색 결과를 직접 보고, 사이트에 노출할 기사만 골라 승인합니다.

- 검색 결과는 DB에 저장되지 않습니다. 화면에 보여주기만 합니다.
- **승인한 기사만** DB에 저장되고 공개 API(`GET /api/news`)로 나갑니다.
- 승인을 취소하면(삭제) 공개 목록에서 즉시 빠집니다.

## 화면

경로 예시: `/admin/news` (ADMIN만 접근)

### 1. 검색 탭

| 요소 | 동작 |
|---|---|
| 검색창 | 기본값 `장기 실종아동`. 1~500자, 공백만 입력 불가 |
| 정렬 | `date`(최신순, 기본) / `sim`(정확도순) |
| 검색 버튼 | 누를 때만 조회합니다. 페이지 진입 시 자동 조회하지 않습니다(네이버 호출 한도 보호) |
| 결과 목록 | 제목, 작성일, 원문 열기 링크, 요약문. 제목·요약에 들어 있는 `<b>` 태그는 강조로 표시하거나 제거 |
| 이전 / 다음 | `start`를 `display`만큼 이동. `start`는 1~1000 |
| [승인] 버튼 | 아래 승인 창을 엽니다. 이미 승인된 기사(409 응답)는 "이미 승인됨"으로 표시 |

**원문 열기**는 새 탭(`target="_blank" rel="noopener noreferrer"`)으로 엽니다. 관리자가 원문을 확인한 뒤 승인하는 흐름입니다.

### 2. 승인 창 (모달)

| 입력 | 필수 | 설명 |
|---|---|---|
| 노출 위치 | O | `HOME` / `MYPAGE` / `BOTH`(기본) |
| 게시 종료일 | X | 비우면 계속 노출. 지정하면 현재보다 이후여야 합니다 (예: 캠페인 기사) |
| 메모 | X | 최대 2000자. 승인 이유 등 내부 기록 |

[승인] 누르면 `POST /api/admin/news`를 호출합니다. 검색 결과의 `title`, `originallink`, `link`, `pubDate`는 **화면이 그대로 실어 보냅니다**(관리자가 입력하지 않음).

### 3. 승인 목록 탭

| 요소 | 동작 |
|---|---|
| 목록 | 제목, 노출 위치, 종료일(지났으면 "종료됨"), 승인 시각, 메모, 원문 링크 |
| 페이지 | `page`(0부터), `size`(기본 20) |
| [노출 중단] 버튼 | 확인 창 후 `DELETE /api/admin/news/{id}`. 되돌리기는 없고, 다시 노출하려면 검색해서 재승인 |

## 인증 (기존 백엔드 규칙 그대로)

- 관리자 = `members.role`이 `ADMIN`인 회원입니다. 권한 부여 API는 없어서 DB에서 직접 바꿉니다.
- 모든 관리자 API에 `Authorization: Bearer {accessToken}` 헤더가 필요합니다.
- **POST·DELETE**에는 CSRF 토큰도 필요합니다.
  1. `GET /api/auth/csrf`를 `credentials: 'include'`로 호출하면 `XSRF-TOKEN` 쿠키가 생깁니다.
  2. 쓰기 요청에 그 값을 `X-XSRF-TOKEN` 헤더로 보내고 `credentials: 'include'`를 붙입니다.
- CORS는 `FRONTEND_ORIGIN`에 등록된 주소만 허용합니다.
- 비로그인은 401, 일반 회원은 403입니다. 401이면 로그인 페이지로, 403이면 "관리자만 사용할 수 있습니다"를 보여주세요.

## 접근 제어와 주의점

### 실제로 막는 곳은 백엔드 API입니다

| 요청 | 비로그인 | 일반 회원(USER) | 관리자(ADMIN) |
|---|---|---|---|
| `/api/admin/news/**` 조회 | 401 | 403 | 통과 |
| `/api/admin/news/**` POST·DELETE | 401 | 403 | CSRF 토큰 있으면 통과, 없으면 403 |
| `GET /api/news` (공개 목록) | 통과 | 통과 | 통과 |

- 권한은 요청마다 DB에서 다시 읽습니다. 관리자 권한을 빼면 이미 로그인한 사람도 다음 요청부터 막힙니다.
- 뉴스 API에는 local 환경 예외가 없습니다(실종자 동기화 API와 다름). 로컬에서도 ADMIN 로그인이 필요합니다.
- 공개 목록(`GET /api/news`)은 의도적으로 공개합니다. 승인 메모(`note`)는 공개 응답에서 빠집니다.

### 프론트에서 할 일

- 페이지 진입 시 `GET /api/members/me`의 `role`이 `ADMIN`이 아니면 관리자 화면을 보여주지 말고, 메뉴에도 관리자 링크를 숨기세요.
- **이 확인은 화면을 숨기는 용도일 뿐 보안이 아닙니다.** 브라우저에서 우회할 수 있으므로, 백엔드가 막는다는 전제로 모든 API 호출에서 401·403을 처리하세요.
- 관리자 화면 코드(번들)는 누구나 내려받을 수 있습니다. 화면 코드에 인증키·내부 주소·비밀 정보를 넣지 마세요. 네이버 인증키는 백엔드 `.env`에만 있습니다.
- 액세스 토큰은 15분이면 만료됩니다. 401이 오면 기존 재발급 흐름(`POST /api/auth/refresh`)을 거친 뒤 다시 시도하고, 실패하면 로그인 페이지로 보내세요.

### 화면에서 지켜야 할 것

- 네이버 검색 결과의 `title`·`description`에는 HTML(`<b>`, `&quot;` 등)이 들어 있습니다. **`dangerouslySetInnerHTML`로 그대로 넣지 마세요.** 태그를 제거하거나 `<b>`만 안전하게 강조로 바꿔 표시합니다.
- 원문 링크는 `target="_blank" rel="noopener noreferrer"`로 엽니다. 서버가 http/https 주소만 저장하지만, 검색 결과(저장 전)는 서버가 검사하지 않은 값이므로 `href`에 넣기 전 `http://`·`https://`로 시작하는지 확인하세요.
- 네이버 검색은 하루 호출 한도가 있습니다. 페이지 진입 시 자동 검색, 입력할 때마다 검색, 반복 새로고침을 하지 마세요. 검색 버튼을 누를 때만 호출합니다.
- [승인]·[노출 중단]은 응답이 올 때까지 버튼을 비활성화해 중복 요청을 막으세요. 중복 승인은 409로 막히지만 사용자에게 혼란을 줍니다.
- [노출 중단]은 공개 목록에서 즉시 빠지므로 확인 창을 띄우세요.

### 아직 없는 것 (필요하면 백엔드에 요청)

- 관리자 권한 부여 API·화면 — 지금은 DB에서 직접 `UPDATE findus.members SET role='ADMIN' WHERE email='…'`
- 프론트 로그인 연동 — `findus-frontend/lib/auth.ts`가 아직 목업이라 관리자 페이지보다 먼저 연결해야 합니다
- 승인한 기사 수정, 누가 언제 노출을 중단했는지 이력

## API

모든 오류 응답은 공통 형식입니다.

```json
{ "code": "INVALID_REQUEST", "message": "사용자에게 보여줄 안내", "errors": [] }
```

`message`는 그대로 화면에 보여줘도 되는 문장입니다.

### 네이버 뉴스 검색 — `GET /api/admin/news/naver`

| 파라미터 | 기본값 | 범위 |
|---|---|---|
| `query` | 설정값(`장기 실종아동`) | 1~500자 |
| `start` | 1 | 1~1000 |
| `display` | 10 | 1~100 |
| `sort` | `date` | `date`, `sim` |

응답은 네이버 API JSON을 **가공 없이** 전달합니다.

```json
{
  "lastBuildDate": "Thu, 22 Oct 2026 10:00:00 +0900",
  "total": 1520,
  "start": 1,
  "display": 10,
  "items": [
    {
      "title": "<b>장기 실종아동</b> 가족 찾기 …",
      "originallink": "https://언론사/기사주소",
      "link": "https://n.news.naver.com/…",
      "description": "요약문 …",
      "pubDate": "Thu, 22 Oct 2026 09:30:00 +0900"
    }
  ]
}
```

| 상태 | 의미 | 화면 처리 |
|---|---|---|
| 503 | 서버에 네이버 키가 설정되지 않음 | "네이버 검색 설정이 필요합니다" + message |
| 429 | 네이버 호출 한도 초과 | "잠시 후 다시 검색해 주세요" |
| 502 / 504 | 네이버 오류·응답 지연 | message 표시, 다시 시도 버튼 |

### 기사 승인 — `POST /api/admin/news`

```json
{
  "title": "<b>장기 실종아동</b> 가족 찾기 …",
  "originalUrl": "https://언론사/기사주소",
  "naverUrl": "https://n.news.naver.com/…",
  "pubDate": "Thu, 22 Oct 2026 09:30:00 +0900",
  "placement": "BOTH",
  "expiresAt": "2026-12-31T23:59:59+09:00",
  "note": "가족 찾기 캠페인"
}
```

- `originalUrl`: 네이버 `originallink`. 비어 있으면 `link`를 넣습니다.
- `title`은 네이버 값을 그대로 보내면 서버가 태그를 제거해서 저장합니다.
- `expiresAt`은 시간대가 포함된 ISO 8601이며, 생략할 수 있습니다.

| 상태 | 의미 |
|---|---|
| 201 | 승인 완료, 응답은 아래 기사 객체 |
| 400 | 잘못된 URL(http/https 아님), 지난 종료일 등 — `errors`에 항목별 안내 |
| 409 | 이미 승인된 기사(같은 원문 URL) |

### 승인 목록 — `GET /api/admin/news?page=0&size=20`

```json
{
  "content": [
    {
      "id": "UUID",
      "title": "장기 실종아동 가족 찾기 …",
      "originalUrl": "https://…",
      "naverUrl": "https://…",
      "publishedAt": "2026-10-22T00:30:00Z",
      "placement": "BOTH",
      "expiresAt": null,
      "note": "…",
      "approvedAt": "2026-10-22T01:00:00Z"
    }
  ],
  "page": 0, "size": 20, "totalElements": 1, "totalPages": 1
}
```

시각은 모두 UTC입니다. 화면에서는 한국 시간으로 바꿔 보여주세요.

### 노출 중단 — `DELETE /api/admin/news/{id}`

- 204: 완료
- 404: 없거나 이미 중단된 기사

## 참고: 공개 API (관리자 화면 아님)

`GET /api/news?placement=HOME|MYPAGE` — 로그인 없이 호출할 수 있습니다. 승인됐고 종료일이 지나지 않은 기사 중 노출 위치가 맞는 것(또는 `BOTH`)을 최대 30건, 승인 최신순으로 줍니다. 항목 형식은 승인 목록과 같고 `note`는 포함하지 않습니다.

## 범위 밖

- 관리자 권한 부여 화면
- 승인한 기사 수정(노출 위치·종료일 변경) — 필요하면 노출 중단 후 재승인
- 검수 이력(누가 언제 중단했는지)
